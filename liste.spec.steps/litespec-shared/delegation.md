# Native delegation (experimental)

Optional search and plan roles with their own models. They do not guarantee token or quota savings; the parent still consumes resources and coordination can increase usage. Native support, loaded configuration, account access and higher-priority instructions determine availability.

Only the matching client may use `delegation-active.md` and its named agents; Zed sharing Codex skill paths does not activate Codex delegation. Roles assist analysis in any phase and mode: search returns evidence with paths/lines, plan returns analysis/proposals. Neither edits nor implements; implementation delegation exists only in Adaptive. Delegate a concrete question that merits a separate context; read known paths and indexes directly. The parent owns design, agreements, spec status, integration and Archive.

Send only the question, necessary paths/evidence, constraints and expected output in a fresh context, not the conversation. Run at most one worker at a time; workers never delegate. Workers read applicable AGENTS.md and the shared protocol. Instructions are not a read-only sandbox in Codex; in Claude, roles are restricted to Read/Grep/Glob. Delegation never expands permissions or authorizes implementation or archive. Workers return findings with paths, uncertainty and open questions; the parent checks what it relies on without repeating the search.

If delegation is unavailable, restricted, unloaded, or fails because of model/effort/quota: report once and continue with the current agent within existing authorization. Do not retry indefinitely, silently select another provider/API, or claim a configured model was actually used without runtime evidence. Distinguish requested model from observed model; native overrides/fallbacks may apply. If continuing is impossible, report the blocker.

Reconfiguration: see the LiteSpec README.
