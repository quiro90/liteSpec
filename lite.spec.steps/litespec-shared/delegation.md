# Native delegation

Only the matching client may use `delegation-active.md` and the agents listed in it. Use `litespec-search` to index files and locate references with paths and lines, `litespec-plan` to analyze existing evidence and prepare a bounded proposal, and `litespec-research` for complex technical questions that need deeper investigation. These roles are read-only and may assist in any phase or mode. Delegate a concrete question that merits a separate context. Read known paths and indexes directly. The parent owns final spec drafting, design, agreements, spec status, integration and Archive.

Send only the question, necessary paths/evidence, constraints and expected output in a fresh context, not the conversation. Run at most one worker at a time; workers never delegate. Delegation never expands permissions or authorizes implementation or archive. Workers return findings with paths, uncertainty and open questions; the parent checks what it relies on without repeating the search.

If delegation is unavailable, restricted, unloaded, or fails because of model/effort/quota: report once and continue with the current agent within existing authorization. Do not retry indefinitely or silently select another provider/API. Never claim a configured model was used without runtime evidence; the client may override or replace it. If continuing is impossible, report the blocker.
