description: Reconcile LiteSpec specs and living docs, verify closure, and archive completed changes.

Read the [shared rules](../litespec-shared/protocol.md).

1. Read active spec.md and step evidence; report unfinished implementation without executing it.
2. Reconcile the same spec and affected steps with verified results/agreed decisions through [revision](../litespec-shared/revision.md) as needed. Never rewrite acceptance to excuse failures; reopened work blocks closure.
3. Update affected notes using [documentation rules](../litespec-shared/documentation.md), then execute [closure](../litespec-shared/closure.md).
